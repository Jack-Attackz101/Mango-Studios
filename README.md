# mango studios

apps, sites, digital products, and other ventures by Jack Koll-Gunderson.

This repo is the home for mango studios work. The marketing site lives at the repo root and deploys from `main` on Vercel. New apps and sites go in `apps/`.

## site

Static pages: `index.html` (home), `sites-and-apps.html`, `ai-agents.html`, `automations.html` and `software.html`, sharing `styles.css`, `main.js` and `assets/`. The menu bar and footer are repeated in each page, so change them in all five.

Open `index.html` locally, or from the repo root:

```
python3 -m http.server 4173
```

The canonical mango mark is `assets/logo.png` — pale yellow fruit, one detached green leaf, soft blue sky. Do not recolor it.
